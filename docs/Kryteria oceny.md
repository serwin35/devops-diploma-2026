# Kryteria oceny pracy dyplomowej

Ocena każdego zadania obliczana jest ze wzoru: **ocena x waga zadania**.

## Skala ocen (0-5)

| Ocena | Znaczenie                                 |
|:-----:|-------------------------------------------|
|   0   | Brak wykonania                            |
|   1   | Brak zrozumienia i błędne wykonanie       |
|   2   | Brak zrozumienia                          |
|   3   | Poprawne zrozumienie                      |
|   4   | Poprawne zrozumienie i poprawne wykonanie |
|   5   | Dobre zrozumienie i dobre wykonanie       |

Skala wagi zadania: **1-6**.
